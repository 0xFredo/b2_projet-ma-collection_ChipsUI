# Readme temporaire (Branche Frontend)

Suivre les étapes dans l'ordre pour lancer l'application.

---

### 1. Activer npm et installer les dépendances

Installer Node.js et npm (https://nodejs.org/en/download/) si ce n'est pas déjà fait.

```bash
# Se place dans le dossier du frontend
cd web

# Installe les dependances du projet
npm install

# Lance le serveur de developpement Vite
npm run dev
```
