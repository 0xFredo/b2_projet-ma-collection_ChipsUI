# ChipsUI

Bienvenue dans ChipsUI, votre nouvelle inerface préférée dédiée à votre collection de chips.

> ***Prérequis :***
>
> - Python 3.14.7 — [Télécharger](https://www.python.org/downloads/)
>
> - Node.JS 24.21.0 — [Télécharger](https://nodejs.org/en/download/)
>
> - Docker Desktop 4.92.0 — [Télécharger](https://www.docker.com/products/docker-desktop/)

## Configuration

**Exécutez le script correspondant à votre système pour configurer ChipsUI.**

***Windows*** : `setup_windows.cmd`

***macOS*** : `setup_mac.sh`

## Exécution

**Exécutez le script correspondant à votre système pour lancer le site.**

***Windows*** : `launch_windows.cmd`

***macOS*** : `launch_mac.sh`
